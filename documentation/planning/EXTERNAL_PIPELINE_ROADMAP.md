### 2. Project-Specific Skill Injection
- **Deskripsi**: Memungkinkan pemuatan agen kustom dari dalam folder proyek eksternal (`.nexus/agents/`).

- **Priority**: Medium

### 3. Atomic Git Checkpointing (Smart Rollback)
- **Deskripsi**: Integrasi dengan Git untuk membuat checkpoint otomatis sebelum modifikasi fisik dilakukan.
- **Status**: Planning
- **Priority**: High

### 4. Cross-Project Knowledge Distillation
- **Deskripsi**: Mekanisme sinkronisasi solusi sukses dari proyek eksternal kembali ke Central HUB.
- **Status**: Planning
- **Priority**: Medium

### 5. Real-time "Shadow" Audit
- **Deskripsi**: Implementasi file watcher untuk mendeteksi pelanggaran standar secara instan saat pengembang sedang bekerja.
- **Status**: Planning
