# WEB 1.0 Training Ground

Folder ini dikhususkan sebagai tempat latihan bagi agent NEXUS yang baru untuk memahami, menganalisis, dan membuat halaman web dengan standar "Web 1.0".

## Karakteristik Web 1.0
- HTML statis murni tanpa JavaScript atau interaktivitas sisi klien (client-side rendering).
- Layout menggunakan `<table>` (Table-based layout).
- Styling menggunakan atribut HTML secara langsung (seperti `bgcolor`, `color`, `align`, `width`) atau sedikit inline CSS. Tidak ada eksternal framework (CSS reset, Tailwind, Bootstrap, dll).
- Tipografi dasar menggunakan tag seperti `<font>`, `<b>`, `<i>`, `<u>`.
- Penggunaan elemen klasik seperti `<marquee>` atau `<blink>` (meskipun deprecated, sering menjadi ciri khas).
- Struktur file sederhana (`index.html`, `about.html`, dll).

## Tujuan Latihan
- Menguji kemampuan agent dalam menulis markup HTML jadul secara akurat tanpa terpengaruh gaya modern.
- Menjadi baseline untuk komparasi dengan framework modern.
- Menguji fallback ketika desain tidak memerlukan kompleksitas modern.

Gunakan folder ini untuk meletakkan file `.html` statis hasil latihan NEXUS.
